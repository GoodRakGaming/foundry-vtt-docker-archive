Пустой том данных = нет лицензии — при первом заходе в Setup новой версии потребуется ввести лицензионный ключ.

Полная миграция тома

→
Копирует ВЕСЬ том источника в назначение (все миры, системы и модули разом), останавливает источник на время копирования. Требует, чтобы назначение было полностью пустым. Для переноса одного мира без остановки источника — панель ДМ.

Перенос мира

→
Не трогает источник, не требует пустого назначения — копирует только выбранный мир (+ его систему, если её ещё нет). То же самое, что в панели ДМ, для удобства.

Копирование модулей

→
Копирует все модули источника, которых ещё нет в назначении. Не трогает источник, не требует остановки. Отдельные селекты от миграции тома — выбор здесь не влияет на кнопку «Мигрировать всё».
